# Neurix Design Research & Visual Directions

> **Scope & Purpose:** **38 concrete, publicly verifiable design references** spanning non-AI desktop & mobile craft software (14), local-LLM & AI product benchmarks (10), OS design guidelines for Windows 11 / macOS / Android (6), and design galleries & showcases (8) — synthesized into **5 mandatory Anti-Claude De-Cloning moves** and **3 candidate visual directions** honoring Neurix's offline local-LLM architecture, alpine/Skardu roots, and Windows + Android parity.

## Part 5: Five Mandatory "Anti-Claude" De-Cloning Moves

1. **Retire `#262624` + `#d97757` as the default theme pair:** Replace Anthropic's olive-brown charcoal & terracotta clay with an unmistakable cool-mineral or botanical-ink flagship palette.
2. **Replace the bottom-left account popover:** Neurix requires zero accounts—replace the Claude-style footer card (`On this device v`) with a sovereign **Local Engine & Memory Status Pill** (loaded model, quant, active RAM/VRAM gauge, one-click model switcher, and explicit Settings gear access).
3. **Break the "centered serif greeting above pill composer" empty state:** Replace `N Hi! What can I help you with?` with a grounded editorial/workspace welcome card showing loaded model capabilities, subtle alpine/topographic motif, and intent starters tailored to current persona/connectors.
4. **Make local-AI craft visibly first-class:** Surface crisp tabular monospace telemetry (`Q4_K_M · 38 tok/s · Vulkan · Offline`), device fit gauges, and non-blocking background model load state across chrome.
5. **Honor Windows 11 & Android natively:** Mica-inspired sidebar + 32px Windows title bar on desktop; bottom-thumb sheet pickers, non-overlapping composer toolbar, and edge-to-edge M3 Expressive motion on Android.

## Part 6: Three Proposed Visual Directions

### Direction 1: **Karakoram Slate** — *Alpine Precision Instrument*
> *References: Linear, Zed, Raycast, Opal, Windows 11 Fluent 2, Skardu granite & glacial water.*
- **Palette:**
  - **Dark (Default):** Sidebar `#0F1317` (recessed), Canvas `#151A20`, Elevated Card/Composer `#1C232B`, 1px Hairline `rgba(255,255,255,0.08)`.
  - **Light:** Sidebar `#EEF2F5`, Canvas `#F8FAFB`, Elevated `#FFFFFF`.
  - **Accents:** **Glacial Teal** (`#2EC4B6` dark / `#0F9D92` light) + **Expedition Brass** (`#E0A458`) reserved strictly for hardware telemetry, downloads, and RAM alerts.
- **Typography:** `Plus Jakarta Sans` / `Inter Display` (`-0.02em` UI/headings), `Inter` (`15px`, `1.65` line-height, `68ch` measure), `JetBrains Mono` (`tnum` tabular numerals for telemetry/code).
- **Signature Visual Motif:** 1.5px geometric linework + subtle 4%–6% opacity **topographic elevation contour lines** in Splash/Onboarding/Model Hub headers.
- **Tradeoffs:** Cleanest, fastest, 100% anti-Claude contrast and Windows 11 alignment; needs Brass warmth & generous whitespace so Friend/Character chats don't feel cold.

### Direction 2: **Deodar & Ink** — *Handcrafted Balti Study*
> *References: Flexoki, Craft v3, Bear 2, Granola, Obsidian, Skardu walnut/deodar woodcraft & archival ink.*
- **Palette:**
  - **Dark:** Deeper obsidian-ink — Sidebar `#10100F`, Canvas `#161614`, Elevated `#1F1E1B`, Hairline `rgba(244,239,230,0.09)`.
  - **Light:** Archival unbleached paper — Sidebar `#EFECE4`, Canvas `#F8F5EE`, Elevated `#FFFDF9`.
  - **Accents:** **Juniper / Alpine Pine** (`#4CA884` dark / `#2F7D5E` light) + **Balti Apricot Gold** (`#D4A359`) for favorites/pins.
- **Typography:** Restrained `Newsreader` / `Instrument Serif` ONLY in editorial empty states & character headings (never chrome buttons), paired with `Inter` (`15.5px`, `1.68` line-height) + `IBM Plex Mono`.
- **Signature Visual Motif:** Minimalist ink-weight emblems + subtle **alpine ridge / woodcarving geometry** for Characters, Friends, and empty states.
- **Tradeoffs:** Extraordinary editorial warmth and light mode beauty for writing/companions; requires strict discipline so dark ink doesn't drift near warm charcoal clones.

### Direction 3: **Balti Monolith** — *Swiss-Alpine Spatial Minimalism*
> *References: Things 3, iA Writer, Notion AI, Superhuman, Apple HIG Materials & Material 3 Expressive.*
- **Palette:**
  - **Dark:** Pure neutral architectural stone — Sidebar `#121213`, Canvas `#171719`, Elevated `#202023`, Hairline `rgba(255,255,255,0.07)`.
  - **Light:** Gallery alabaster — Sidebar `#F3F3F2`, Canvas `#FAFAFA`, Elevated `#FFFFFF`.
  - **Accents:** **High-Altitude Lapis Cobalt** (`#4F86F7` dark / `#2563EB` light) + optional **OS System Accent**.
- **Typography:** `Geist` (`Segoe UI Variable` / `Roboto Flex` parity fallback) with weight-driven hierarchy + `Geist Mono`.
- **Signature Visual Motif:** Borderless `68ch` reading stream, strict Fluent/HIG plane separation, single animated **alpine-peak / acoustic wave** loader during generation.
- **Tradeoffs:** Highest native Windows + Android harmony that ages cleanly; relies completely on typography, spacing, and motion polish to stand out.

### Direction Comparison Matrix

| Dimension | 1. Karakoram Slate | 2. Deodar & Ink | 3. Balti Monolith |
|---|---|---|---|
| **Core Identity** | Alpine precision instrument | Handcrafted mountain study | Swiss-alpine spatial quiet |
| **Visual Distance from Claude** | **Maximum** (cool basalt + glacial teal) | **High** (obsidian ink + juniper pine) | **Maximum** (neutral stone + lapis/system) |
| **Signature Accents** | Glacial Teal (`#2EC4B6`) + Brass (`#E0A458`) | Juniper Pine (`#4CA884`) + Apricot Gold (`#D4A359`) | Lapis Cobalt (`#4F86F7`) / OS Accent |
| **Skardu Craft Motif** | Granite, glacial meltwater, topo contours | Deodar cedar, archival ink, woodcarving ridge | High-altitude lapis sky, spatial alignment, wave pulse |
| **Strongest Use Case** | Daily local-LLM workstation, code, Model Hub | Creative writing, Friends/Characters, long reading | Purest cross-platform Windows + Android native feel |
| **Track 4 Synthesis Note** | **Recommended Flagship Default** (`Direction 1`) | Signature Warm Alternate (`Direction 2`) | Cross-Platform Fluent 2 / M3 Structural Spine (`Direction 3`) |

> **Recommendation:** Pair **Direction 1 (*Karakoram Slate*)** as Neurix's flagship default theme with **Direction 2 (*Deodar & Ink*)** as the warm editorial alternate, built atop **Direction 3's** cross-platform Fluent 2 + Material 3 structural discipline.

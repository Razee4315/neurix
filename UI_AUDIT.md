# Neurix UI/UX Audit (Baseline -> Redesign Targets)

Screen-by-screen visual and interaction audit grounded in all **21 captured baseline screenshots** (`docs/mission/baseline/*.png`) on `v1.0.0` native and `v1.0.1` (`eb8b544`) Playwright walkthroughs.

---

## Global Shell, Navigation & Cross-Cutting Issues

1. **Claude Desktop Clone Identity ([desktop-chat-welcome.png](docs/mission/baseline/desktop-chat-welcome.png))**:
   - **Defect:** Warm charcoal `#262624` + terracotta `#d97757`, centered editorial serif greeting over pill composer, left rail `+ New chat` orange circle, and bottom-left `"On this device v"` account-like popover closely mirror Anthropic's Claude Desktop.
   - **Prescription:** Adopt **Karakoram Slate** (`#0F1317` recessed sidebar, `#151A20` reading plane, Glacial Teal `#2EC4B6` primary, Expedition Brass `#E0A458` telemetry accent). Replace the bottom-left popover with a **Local Engine Status Pill** (model name, quant, load spinner, quick settings trigger).
2. **Missing `System` Auto-Theme ([desktop-settings.png](docs/mission/baseline/desktop-settings.png))**:
   - **Defect:** Only 4 fixed swatches; changing Windows dark/light mode never updates Neurix automatically.
   - **Prescription:** Retain 4 distinct theme definitions (`Karakoram Slate`, `Paper`, `Deodar`, `Phosphor`) + add a top-level **`Match System`** toggle tracking `(prefers-color-scheme: dark)` -> `Karakoram Slate` / `light` -> `Paper`.
3. **Windows DPI Window Clipping ([native-v1.0.0-settled.png](docs/mission/baseline/native-v1.0.0-settled.png))**:
   - **Defect:** Right edge of frameless custom title bar shows minor sizing friction at 125% DPI; `New chat` button duplicates in both sidebar and chat header.
   - **Prescription:** Standardize a crisp integrated 32px–40px Windows title bar (`TitleBar.tsx`) with clear drag zone, Snap hover alignment, and remove redundant header icons when sidebar is expanded.
